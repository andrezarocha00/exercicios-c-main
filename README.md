💻 Exercícios em Linguagem C

Bem-vindo(a)! 🚀

Este repositório reúne os exercícios que desenvolvi durante meus estudos de Linguagem C na graduação em Análise e Desenvolvimento de Sistemas.

O objetivo é registrar minha evolução, praticar lógica de programação e criar o hábito de desenvolver soluções cada vez mais organizadas.

---

📚 Conteúdo

Ao longo deste repositório você encontrará exercícios envolvendo:

- 🔢 Operações matemáticas
- ➕ Funções e parâmetros
- 🔁 Estruturas de repetição ("for", "while")
- 🔀 Estruturas de decisão ("if", "switch")
- 🧠 Recursividade
- 📦 Vetores
- 🔤 Strings
- 👉 Ponteiros
- 📐 Cálculos geométricos
- 💰 Juros simples e compostos
- ⚙️ Modularização com funções

---

🛠️ Tecnologias

- Linguagem C
- GCC
- Code::Blocks / Dev-C++ (dependendo da atividade)
